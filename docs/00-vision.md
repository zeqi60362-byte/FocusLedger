# 00 · 定位与愿景

## 一句话

**FocusLedger 是一个本地优先的注意力审计工具：它不相信你的计时器，只相信证据。**

## 问题

知识工作者（尤其是研究生）普遍存在**时间感知失真**：

1. **自报时长系统性偏高**。番茄钟、Forest、Toggl 记录的是"你按下了开始"，不是"你在工作"。
   计时器不会因为你离开而暂停。
2. **失真是不可见的**。用户知道"我可能高估了"，但不知道高估多少、高估在哪个时段、为什么会高估。
3. **现有工具只回答"花了多久"，不回答"值不值"**。RescueTime 给你应用时长排行，
   但不告诉你那 2 小时 Chrome 是在读论文还是在刷视频。
4. **没有可纠正的反馈回路**。用户看到"6 小时"，也无法验证这个数字。

## 用户

**核心用户（第一阶段）**
- 在读硕博研究生：读文献、写代码、跑数据、写论文，长时间在电脑前，对"有效工作时长"有强需求
- 需要向导师/自己交代进度的人

**扩展用户（第二阶段）**
- 知识工作者、独立开发者、自由职业者（按小时计费的人对"真实工时"极度敏感）
- ADHD / 注意力困难群体——这个群体对"诚实的用时反馈"需求最强，但也是最容易被"监控感"劝退的群体，
  文案必须极其小心

**明确不服务的用户**
- 企业主想监控员工。这是产品的法律与道德红线，不做 B2B 监控版。

## 差异化

| 维度 | 竞品现状 | FocusLedger |
|---|---|---|
| 数据源 | 应用 / 窗口 / 键鼠空闲 | 应用 + 窗口标题 + 画面变化 + 媒体播放 + 音频 + 锁屏 + 意图声明 |
| 判定 | 二元（活跃/空闲） | 七状态 + 置信度区间 |
| 输出 | 时长排行 | 时长 + 有效性 + 差额归因 |
| 反馈 | 事后统计 | 意图声明 → 实时偏离提醒 → 日终对账 |
| 隐私 | 多数上云 | 默认纯本地，网络功能显式 opt-in |

**护城河的正确理解**：基础采集层没有壁垒（ActivityWatch 已经开源且成熟）。
壁垒在 **判定模型 + 对账方法 + 长期校准的个人基线数据**。这三样可以沉淀为软件著作权与发明专利。

## 三层能力

- **L1 记录（What）**：我在哪些应用、窗口、项目上花了多久
- **L2 判定（How engaged）**：这些时间是深度投入、被动接收、离席，还是在摸鱼
- **L3 归因与干预（Why & Fix）**：为什么今天有效时间只有 3.2 小时，明天怎么改

MVP 必须把 L1 和 L2 做扎实，L3 只做"归因报告"，不做"建议引擎"（建议容易变成说教）。

## 商业模式（后续，不在 MVP）

开源策略：MPL-2.0 开放全部桌面端源码，建立可审计的信任基础。

可变现的方向（按可行性排序）：
1. **Pro 版授权**（闭源增量功能）：云端同步、跨设备、周报 PDF 导出、LLM 复盘摘要
2. **买断制**：一次性付费解锁 Pro 功能，不做订阅（学生对订阅反感）
3. **赞助 / GitHub Sponsors**：开源项目的常规路径，作为补充
4. 团队版：**只在有"被监控方知情同意"机制的前提下**做，否则不做

定价锚点参考：RescueTime Premium ≈ $12/月，Forest ≈ $4 买断，Toggl ≈ $9/人/月。
FocusLedger 的合理位置是 **¥99–199 买断**，或以"学生免费 + 自愿付费"起步换取口碑。

## 命名

- 英文仓库名：`FocusLedger`（账本 = 对账，直接对应核心功能）
- 中文名：**专注账本**
- 备选：`Attest`（作证）、`真时`、`Reckon`

## 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 被判为"监控软件" | 致命，杀软误杀 + 用户反感 | 开源、默认本地、托盘可见、一键暂停、绝不采集内容 |
| 判定不准 | 高，用户被骗一次就不再用 | 输出置信区间、允许一键纠正、日终复核 |
| 电池与性能 | 中，笔记本电脑用户敏感 | 严格性能预算（CPU < 1%），离席降频 |
| 与 ActivityWatch 同质化 | 中 | 不做"又一个记录器"，只做判定与对账；可评估复用其 watcher 协议 |
| 单人维护不可持续 | 高 | 严格模块边界 + 自动化测试，降低后期维护成本 |

## 非目标

- 不做摄像头人脸 / 眼动检测（隐私成本远高于准确率收益）
- 不做生产力排行榜、不做游戏化积分、不做"羞辱式"提醒
- 不做手机端、不做团队管理后台（MVP 期内）
- 不做"AI 替你规划一天"这类建议功能
