# 01 · 产品规格

> **专注账本 · 每一分钟都对得上**
>
> Focus ledger · every minute accounted for

**状态**：定稿 v1.0（2026-11-01）
**地位**：本文是唯一实现依据。实现与本文冲突算 bug；需要变更时先改本文，并在 `06-decisions.md` 追加一条 ADR。

---

## 1. 产品定义

产品定位是**注意力审计，不是时间记录**（ADR-001）：记录解决「花了多久」，判定解决「值不值」，
对账解决「差在哪」。记录只是输入。

FocusLedger 是一个 Windows 桌面应用，常驻系统托盘，按 **5 秒采样**、按 **60 秒判定**，
把一天的电脑使用切分为七种状态，并在日终生成「声称 vs 实证」的对账报告。

### 三个不变量（违反任何一条都算设计失败）

- **I1 不假装精确**：任何时长输出必须带置信区间。禁止只输出一个看似精确的数字。
- **I2 不采集内容**：只采集结构与计数（应用名、窗口标题、事件次数、哈希），不采集任何文本内容。
- **I3 可被推翻**：用户对任何一段判定都能一键改判，且改判结果永久优先于模型输出。

## 3. 功能需求

### 3.1 采集（Collector，Windows）

| ID | 需求 | 验收 |
|---|---|---|
| FR-A1 | 采集前景窗口：进程名、进程完整路径、窗口标题、HWND；事件驱动，切换捕获延迟 ≤ 500 ms | 切换窗口 10 次，记录数与实际一致 |
| FR-A2 | 采集系统空闲时长：`GetLastInputInfo`，1 s 轮询，记录自上次输入以来的秒数 | 手动不动鼠标，数值单调递增 |
| FR-A3 | 采集键鼠活动**次数**：低级钩子只做计数，绝不记录键码、坐标、内容 | 代码审查 + 全局搜索确认无 keycode 变量 |
| FR-A4 | 采集画面变化：每 5 s 对前景窗口做 9×8 灰度采样，计算 64 位 dHash，只保存哈希与相邻帧的汉明距离 | 静止页面距离≈0；滚动/视频距离明显 > 0 |
| FR-A5 | 采集媒体播放状态：Windows SMTC，记录播放/暂停/停止、来源应用、媒体标题 | 播放音乐/视频时能读到 playing |
| FR-A6 | 采集音频输出峰值：`IAudioMeterInformation`，0–1 | 静音时≈0，播放时有值 |
| FR-A7 | 采集会话状态：锁屏 / 解锁 / 注销、睡眠 / 唤醒；关机或崩溃前必须 flush | 锁屏 1 分钟，该区间状态为 locked |
| FR-A8 | 排除列表：按进程名、按窗口标题正则、按时间段（如 22:00–08:00 不记） | 命中后不落库 |
| FR-A9 | 暂停开关：托盘一键暂停，暂停期间不采集、不落库 | 暂停 5 分钟后无新样本 |
| FR-A10 | 采集健康度：丢帧计数、采集错误计数，可在设置页查看 | 人为制造异常后计数 +1 |

### 3.2 判定（Inference）

| ID | 需求 | 验收 |
|---|---|---|
| FR-B1 | 规则引擎把 `(进程名, 窗口标题)` 映射为类别与上下文系数 `C`（1.0 任务 / 0.6 中性 / 0.0 分心），规则可排序、可编辑、可禁用 | 内置规则包覆盖常见应用 |
| FR-B2 | 每 60 s 聚合一个窗口，计算特征向量 `A, V, S, P, C, idle` | 单测 |
| FR-B3 | 状态机输出七状态之一 + 权重 + 置信区间 `[w_lo, w_hi]`，规则见 `02-state-machine.md` | 8 个验收场景全过 |
| FR-B4 | 两遍制：实时给出 `provisional` 状态；日终重算 `final` 状态。UI 默认展示 final，并标明"已校正" | 同一段数据两次结果可复现 |
| FR-B5 | 返回修正：短间隔离开后回归，可把该区间从 `idle_away` 重判为 `silent_focus` | 场景 S5 通过 |
| FR-B6 | 可解释：每个 segment 保存触发的规则 ID 与特征快照，UI 能展示"为什么判成这样" | 点击任意段落下钻可见 |
| FR-B7 | 用户改判：任意区间可改为指定状态，写入 `labels` 表，并优先于模型结果 | 改判后立即生效且重启后保留 |

### 3.3 存储（Storage）

| ID | 需求 |
|---|---|
| FR-C1 | SQLite（WAL 模式），单文件，位于 `%LOCALAPPDATA%\FocusLedger\data.db` |
| FR-C2 | 保留策略：原始样本 14 天（可配 7/14/30/永不）、segments 1 年、日聚合永久；每日凌晨执行清理 |
| FR-C3 | 导出：CSV（样本/段/日报）与 JSON（含 schema 版本），导出时默认对窗口标题脱敏 |
| FR-C4 | 一键删除全部数据，需二次确认，删除后不可恢复 |
| FR-C5 | 数据库迁移：`schema_version` 单调递增，升级脚本幂等、可回滚（备份后执行） |

### 3.4 呈现（UI）

| ID | 需求 |
|---|---|
| FR-D1 | 托盘常驻：图标区分"记录中 / 已暂停"，右键菜单含 暂停、排除当前应用、打开面板、退出 |
| FR-D2 | 今日时间轴：横向色带，按状态着色，支持缩放（1 天 / 6 小时 / 1 小时），悬停显示应用与标题 |
| FR-D3 | 日报页：五段式（深度 / 被动 / 存疑 / 分心 / 离席）+ 有效时长与区间 + 分心 Top5 应用 |
| FR-D4 | 下钻：点击任意时间片弹出解释卡（应用、标题、输入次数、画面变化、媒体状态、触发规则） |
| FR-D5 | 规则编辑：类别、匹配方式、正则、优先级；支持"用当前窗口新建规则" |
| FR-D6 | 日终复核：列出所有 `ambiguous`、`silent_focus` 与低置信区间，键盘左右键快速标注 |
| FR-D7 | 意图声明：设置时长与预期应用，开始后托盘图标变为"进行中"，结束弹出遵守率 |

### 3.5 对账（Reconcile）

| ID | 需求 |
|---|---|
| FR-E1 | 支持导入番茄 Todo / Forest / Toggl 的 CSV，字段映射可配置，导入前去重 |
| FR-E2 | 对齐算法：把"声称区间"按时间轴切分，与 `final` 状态求交集，输出五类差额归因 |

## 5. 边界情况（必须处理）

1. **多显示器 + 不同 DPI 缩放**：捕获与坐标计算用物理像素，不得因缩放崩溃。
2. **全屏独占应用 / 游戏**：全屏时降频采样，避免掉帧。
3. **DRM 视频（Netflix 等）**：截图返回黑帧，此时以 SMTC 媒体状态为主判据，不得判为"静止"。
4. **远程桌面**：RDP 会话中采集应暂停或标记，避免记录到远端机器的画面。
5. **系统时间被修改 / 时区变更 / 夏令时**：用单调时钟计算间隔，UTC 存储，禁止出现负时长。
6. **休眠唤醒 / 断电**：重启后不得出现"幽灵时长"，缺口标记为 `unknown_gap`。
7. **多用户同时登录**：只采集当前交互会话。
8. **标题为空**（UWP 应用）：回退到进程名 + UI Automation 名称，仍失败则标 `title_empty`。
9. **杀软拦截低级钩子**：降级为纯 `GetLastInputInfo`（仅空闲、无计数），并在设置页提示能力受限。

## 6. 文案规范

- 只陈述事实，不做评判。禁止："你今天很懒""又分心了""效率低于 80% 的用户"。
- 允许："今天有 1.4 小时离席，0.9 小时在社交应用"。
- 离席 = 中性词，不等于"浪费"。
- 首次使用不出现任何红色警告。
