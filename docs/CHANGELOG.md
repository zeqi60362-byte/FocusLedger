## v0.7 · 2026-11-03 · 周期任务

### 计划：重复规律

编辑器新增「重复」一段（只在新建时出现）：**不重复 / 每天 / 工作日 / 休息日**，
下面一排「一二三四五六日」可以自选星期，点任意一个就切到自定义；
选了重复后再出现「持续」一行，可选 **1 / 2 / 4 / 8 / 12 周**（默认 8 周）。

### 界面

- 规则页：「匹配」表头和「刚才在用的窗口」加粗、改用正文色、字号 +0.5–1

## v0.5 · 2026-11-03 · 计划页可滚动 + 建表重复列修复

### 修复：新装用户启动即崩

`plans` 的建表语句里 `location / url / remind` 被写了两遍，`MigratePlans()` 里也重复了两组
`if (!columns.Contains(...))`。两个后果：

- 全新安装：`CREATE TABLE` 直接抛 `SQLite Error 1: 'duplicate column name: location'`，
  库都建不起来；
- 老库升级：列快照在方法开头取一次，第一组加完列后快照没变，第二组会照着过期快照再
  `ALTER` 一遍，同样抛 `duplicate column name`。

本机之所以一直没炸，是因为那份 `data.db` 三列早就齐了，两处都被 `IF NOT EXISTS` / `Contains` 跳过。
Storage 测试（新建库 + 老库各一条路径）把两边都照出来了。

改为 `Ensure(列名, 定义)` 单列单判，加完立刻记进快照。

### 计划页可滚动

上下堆叠之后，页面用的是「星号行 + GridSplitter 分剩余空间」，外层没有滚动容器，
窗口一矮内容就被裁掉，而且整页滚不动。

- 换成「固定高度 + 滚动」：周视图卡片给定高度（默认 480），月历按内容自适应，
  两者一起放进 `ScrollViewer`；顶栏留在滚动容器外面，始终可见
- 分隔条不再分星号行，改成拖拽时直接改 `WeekCard.Height`（320–1400 之间夹紧）；
  星号行在 `ScrollViewer` 里拿不到确定高度，本来也拖不动
- `HorizontalScrollBarVisibility` 必须是 `Disabled`：横向一开，`ScrollViewer`
  会用无限宽去量 `WeekCanvas`，最右一列又会被切掉（v0.4 踩过一次）

### 界面细节

- 滚动条不再显示：五个页面的 `ScrollViewer` 全改 `VerticalScrollBarVisibility="Hidden"`
  （可滚、不画、不占位），`ScrollBar` 的隐式样式宽度也归零兜底
- 今日页标题「意图声明」→「设定今日专注任务」
  （上一笔 `34d9b23` 只改了字号字重，文案本体在 `Localization.cs` 里根本没动）
- 今日页「意图卡 → 主数字卡」间距 28 → 14，与「主数字卡 → 时间轴卡」一致
  （`IntentPanel` 自带的 14 底边距和外层卡片的 14 上边距叠在一起了）
- 统计页汇总卡删掉「深度工作块 … 应用切换 …」一行，四种状态的胶囊之后不再留大段空白
- 今日页下钻卡：没点过时间轴时直接显示**当前正在用的那一段**（时间/状态/应用/标题），
  不再先显示一句占位提示；卡片给一个最小高度，点与不点页面都不会跳
- 计划页色块改成实色：原先半透明底会让背后的横向刻度线透过来，一块 5 小时的计划
  看上去像被切成几段；同时块内标题 / 地点 / 网址三行居中显示（放不下就少画几行）

## v0.2 · 2026-11-01 · 判定模型重构 + 界面调整

### 判定：七状态 → 四状态

用户实际使用两天后反馈：被判成「静默专注」的时间，其实是他离席去接水、上厕所。
原模型把「无输入但在任务应用里」当作静默专注，过于宽松——这正是番茄钟高估的老路。

**新模型（`ActivityState`）：**

| 状态 | 判定 | 权重 |
|---|---|---|
| 深度专注 | 有键鼠输入 + 工作类应用 | 1.00（中性上下文 0.75） |
| 静默专注 | 手不动，但在看/听学习内容（有媒体播放或画面在变） | 0.85 / 0.70 |
| 分心 | 娱乐、社交、购物 | 0 |
| 离席 | 其余一切，含锁屏 | 0 |

**核心原则改为：没有正面证据就算离席。** 宁可少算，也不要把「人不在」算成「在思考」。

- 移除 `PassiveFocus`（合并进静默专注）
- 移除 `Locked`（并入离席）
- 移除 `Ambiguous`（默认落到离席）
- 移除「返回修正」——它会把离开几分钟改判成在思考，正是判错的那一类

### 规则：学习关键词

B站、小红书、知乎默认算分心，但标题含学习关键词（考研、课程、教程、公开课、讲座、
论文、文献、编程、算法……）时改判为学习内容，优先级 8，压过所有应用级规则。

### 界面

- 移除「对账」页，导入计时器 CSV 移到设置页
- 日报下新增统计：逐周 / 逐月 / 逐年
- 新增「计划」页：月历 + 7:00–22:00 时间表 + 香港 2026 法定假期
- 今日页下钻卡片精简：只保留时间、状态、应用、标题
- 全局字体统一为 Microsoft YaHei UI

### 未完成

- 中英文切换（i18n）：待界面稳定后再做，避免翻译一批即将改动的文案
- 日历的节假日 CSV 导入界面（当前仅内置香港 2026）
