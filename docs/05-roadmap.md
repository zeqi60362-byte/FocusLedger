# 05 · 路线图

原则：**每个里程碑必须能运行、能演示、能被非程序员验收**。
不允许出现"代码写完了但要等下一个里程碑才能看到东西"的情况。

---

## M0 · 信号探针（半天）

**状态**：✅ 基本完成 —— 5/5 信号 API 已验证（窗口、空闲、画面、媒体、锁屏）。
媒体 `Playing` 与 `locked` 分支待真实场景复验。实测结论见 [m0-findings.md](m0-findings.md)。

**目标**：证明这台电脑能采到所有关键信号，且成本可接受。

**交付**
- `tools/probe.ps1`：实时打印 前景应用 / 窗口标题 / 空闲秒数 / 画面变化 / 媒体状态
- 运行 5 分钟，记录 CPU 与内存占用
- 一份 `docs/m0-findings.md`：哪些信号可用、哪些被拦、画面变化的实际分布

**验收（你可以自己看）**
1. 双击 `probe.ps1` 就能跑，不需要装任何东西
2. 切换窗口时，打印的应用名会立刻变
3. 你离开键盘 30 秒后，空闲秒数持续增长
4. 静止页面时画面变化值接近 0；滚动或播放视频时明显变大
5. 任务管理器里看到的 CPU 占用 < 1%

**失败预案**：若画面采样被安全策略拦截，退化为"媒体状态 + 空闲 + 输入"三信号，判定模型降级但仍可用。

## M1 · 采集落库 + 命令行日报（2–3 天）

**状态**：✅ 完成，待验收。完成报告见 [m1-report.md](m1-report.md)。

**目标**：第一次看到真实的"我的时间去哪了"。

**交付**
- `FocusLedger.Core` 完整实现（特征聚合 + 状态机 + 两遍制）
- `FocusLedger.Collector.Windows` 全部采集器
- `FocusLedger.Storage` 建库、写入、保留清理
- `FocusLedger.Cli`：
  ```
  focusledger report --date today
  ```
  输出：
  ```
  2026-11-01  有效专注 4.2h [3.8–4.6]
    深度 3.1h | 被动 1.1h | 存疑 0.6h
    分心 0.9h | 离席 1.4h | 锁屏 2.1h
    深度工作块 5 次，最长 52 分钟
    分心 Top3：WeChat 32m / bilibili 21m / Steam 14m
  ```
- `tests`：8 个验收场景全绿

**验收**
1. `dotnet test` 全绿
2. 让程序跑一整天，第二天早上 CLI 能输出昨天的报告
3. 报告里的数字和你自己的体感大致对得上（误差 < 20%）
4. 故意离开 30 分钟，报告里这 30 分钟不在"有效专注"里

## M2 · 托盘 + 时间轴 + 日报界面（3–4 天）

**状态**：✅ 核心完成 —— 托盘、时间轴、日报、设置均已跑通；**规则编辑页延后到 M2.5**。
完成报告见 [m2-report.md](m2-report.md)。

**目标**：从"能用"到"想每天看"。

**交付**
- 托盘常驻（记录中/已暂停图标、右键菜单、开机自启）
- 今日时间轴：横向色带、缩放、悬停、点击下钻解释卡
- 日报页：五段式 + 区间 + 分心 Top5
- 规则编辑页：用当前窗口一键建规则
- 排除列表、暂停开关
- 设置页：采样参数、保留策略、导出、删除全部数据

**验收**
1. 安装后 3 分钟内看到第一条时间轴，全程无需命令行
2. 时间轴的颜色分布和你的实际一天基本吻合
3. 点击任意一段，能看到"为什么判成这样"（应用、标题、输入次数、画面变化、命中规则）
4. 你能自己加一条规则，让某个应用从"分心"变成"任务"
5. 暂停后不再记录，图标状态同步变化

**风险点**：WPF 视觉不达标时，启动 §7 的 WebView2 备选方案。

---

## M3 · 意图声明 + 对账（2–3 天）

**目标**：产品的传播点成型。

**交付**
- 意图声明：设定时长 + 预期应用，结束算遵守率
- 番茄 Todo CSV 导入（字段映射界面）
- 对账卡：声称 vs 实证 + 差额归因 + 可导出 PNG
- 日终复核：低置信区间快速标注（键盘左右键）

**验收**
1. 导入你过去一周的番茄记录，生成的差额图你能认可
2. 对账卡截图发到群里，别人能看懂在说什么
3. 日终复核 60 秒内能标完一天
4. 标注后重新出报告，数字随之变化

---

## M4 · 打包与开源发布（2 天）

**目标**：别人能下载、能装上、能信任。

**交付**
- 单文件发布 + Velopack 安装器 + 自动更新
- 首次启动隐私说明与同意页（60 秒内读完）
- `README` 配截图与 GIF、`CONTRIBUTING`、`SECURITY`、Issue 模板
- 隐私政策（中文 + 英文）
- GitHub Actions：构建 + 测试 + 发布
- 许可证：MPL-2.0（见 ADR-003）

**验收**
1. 找一台没装过 .NET 的电脑，双击安装包能装能跑
2. 断网状态下功能完整
3. 杀软不报警（或能给出白名单说明）
4. GitHub 仓库首页能让人 30 秒内明白这是什么
