# 07 · 隐私与合规

这个品类里，**信任就是产品**。任何一条红线被越过，项目就死了，没有第二次机会。

---

## 1. 数据清单（采集什么、为什么、存多久）

| 数据 | 用途 | 是否离开本机 | 保留 |
|---|---|---|---|
| 进程名 | 分类 | 否 | 14 天（原始）/ 1 年（聚合） |
| 窗口标题 | 分类（区分同一浏览器里的论文与视频） | 否 | 同上 |
| 键鼠**次数** | 判断是否有输入 | 否 | 同上 |
| 系统空闲秒数 | 判断是否离席 | 否 | 同上 |
| 画面 dHash（64 位整数） | 判断画面是否在变 | 否 | 同上 |
| 媒体播放状态 | 区分看网课与发呆 | 否 | 同上 |
| 音频峰值（0–1） | 区分有声/无声媒体 | 否 | 同上 |
| 锁屏/休眠事件 | 排除非使用时间 | 否 | 同上 |

**绝不采集**：按键内容、按键时长、鼠标坐标轨迹、剪贴板、文件内容、文件名（仅窗口标题中的一部分）、
浏览器 URL 与历史、摄像头、麦克风、位置。

## 2. 红线（实现层面不可协商）

1. **零出站网络**。应用进程内不出现任何 HTTP/Socket 代码，CI 反射扫描强制检查（ADR-010）。
2. **不落盘截图**。画面采样只保留 64 位哈希与汉明距离，图像缓冲用完立即清零并复用。
3. **不记录内容**。低级钩子回调内只允许原子自增计数；代码评审时逐行确认。
4. **托盘可见**。记录中必须有可见图标；不允许"静默运行、托盘隐藏"。
5. **一键暂停**。暂停立即生效（≤ 1 秒），暂停期间不写任何样本。
6. **一键排除**。支持按应用、按标题正则、按时间段排除；排除的应用即使在后台也不记录标题。
7. **数据可带走、可销毁**。一键导出、一键删除，删除需二次确认，删除后不保留任何残留（含日志中的标题）。
8. **首次启动知情同意**。60 秒内可读完的说明 + 明确的"我同意"按钮，默认不勾选，不做暗黑模式。

## 3. 威胁模型

| 威胁 | 场景 | 缓解 |
|---|---|---|
| 同事/家人看到屏幕 | 他人路过看到时间轴上的邮件标题 | 标题在 UI 中默认截断为 30 字符；提供"演示模式"隐藏标题 |
| 笔记本丢失 | 硬盘被读取 | 提供可选的 SQLCipher 加密（设置项，默认关闭以换取性能） |
| 恶意软件读取数据库 | 同机其他进程 | 数据库位于 `%LOCALAPPDATA%`，ACL 限当前用户；可选加密 |
| 被误认为监控软件 | 公司 IT 或同学看到 | 开源代码、README 显著声明、首次启动说明 |
| 导出文件外泄 | 分享对账卡时带上标题 | PNG 导出**不带**任何标题；CSV 导出默认脱敏 |
| 供应链 | 依赖包投毒 | 锁定版本、最少依赖、启用 NuGet 签名验证 |

## 4. 合规

### 4.1 中国《个人信息保护法》
- 本产品处理的是**用户本人**的个人信息，且全部本地处理，不构成"对外提供"。
- 若将来做云同步：需单独告知 + 单独同意 + 提供关闭选项；不得默认开启。
- **绝不做员工监控版**。即使客户付费也不做——这是产品价值观的一部分，写进 README。

### 4.2 GDPR（若面向海外发布）
- 数据控制者 = 用户本人，处理者 = 无（本地处理）。
- 提供数据可携带（导出）与删除权（一键删除），天然满足 Art. 15/17/20。
- 不做任何 profiling 用于广告。

### 4.3 开源合规
- MPL-2.0：分发修改版时必须公开修改的源文件，并保留版权声明。
- 第三方依赖许可证需在 `THIRD-PARTY-NOTICES.md` 列明。

## 5. 反误杀（重要且容易被忽略）

时间监控类软件是杀毒软件的重点关注对象，尤其涉及低级键鼠钩子。

缓解措施：
1. **代码签名证书**（OV 起，EV 更好），并保持签名一致性。
2. 钩子只在应用运行期间注册，退出时确保卸载；设置 `LowLevelHooksTimeout` 避免系统被拖慢。
3. 在 README 与官网提供"为什么会被误报"的说明与 VirusTotal 链接。
4. 提供**无钩子模式**：完全不用低级钩子，只依赖 `GetLastInputInfo`。
   该模式判定精度下降，但可绕过绝大多数误报。
5. 提交微软 Defender 的误报申诉通道。

## 6. 首次启动流程（60 秒内）

1. **一句话**：FocusLedger 记录你在电脑上的时间分布，全部存在本机。
2. **我们记录什么**：应用名、窗口标题、键鼠次数、是否离开、画面是否变化。
3. **我们不记录什么**（用图标 + 红色删除线，最醒目）：按键内容、剪贴板、文件内容、截图、摄像头。
4. **你能控制什么**：随时暂停、随时排除某个应用、随时删除全部数据。
5. **按钮**：`我同意，开始记录` / `先不记录，只看看界面`

不做倒计时、不做"不同意就退出"。

## 7. 披露义务

README 首页必须显著包含：
- 一张"数据流向图"（本机 → 本机，没有云）
- 一段"我们不采集什么"
- 数据删除方式
- 已知局限（判定不可能 100% 准确，请配合日终复核）

隐瞒局限比隐瞒缺陷更致命。用户能接受"它有时候会判错"，不能接受"它假装自己不会错"。
